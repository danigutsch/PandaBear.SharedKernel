# SharedKernel.Testing.Web

Reusable bUnit element assertions for SharedKernel web test suites.

## Usage

Use `BunitElementAssertions.HasClass` with the element class list and expected class in bUnit component tests. The caller owns component rendering, service registration, and accessibility expectations.
