### Controlled metadata time

Set `PostgreSqlEventSourcingOptions.TimeProvider` when constructing either store with a controlled clock.
Existing constructors default to `TimeProvider.System`. Capture the application-registered provider in this options
object when composing the stores; the package remains independent of a DI host. Each nonempty append reads the
clock once after acquiring the append lock, before stream creation, and reuses that instant for stream creation,
every event, and the stream revision update. Later appends preserve stream creation time. Checkpoint saves use
the configured clock. PostgreSQL timestamps retain the database's microsecond precision; UUIDv7 IDs remain
independently generated by the event store.
