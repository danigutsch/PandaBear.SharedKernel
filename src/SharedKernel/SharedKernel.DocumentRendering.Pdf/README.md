# SharedKernel.DocumentRendering.Pdf

This optional package normalizes the timestamps of fresh tagged Chromium
PDFs generated by a renderer the caller owns. The existing
[structured HTML renderer](../SharedKernel.DocumentRendering/README.md)
has its own synchronous API. Use a privately provisioned absolute path
to the qpdf executable and its qualified native runtime. The host also
owns the pinned Chromium binary and fonts.

Pass a byte limit and a deadline to the normalizer. Supply an immutable
document date chosen by the host. The operation converts it to UTC and
keeps second precision, matching Chromium's PDF Info date format.

```csharp
using PandaBear.DocumentRendering.Pdf;

var normalizer = new QpdfDocumentNormalizer(qpdfPath, maximumPdfBytes, timeLimit);
var pdf = await normalizer.Normalize(generatedPdf, approvedDocumentDate, cancellationToken);
```

The input must match the qualified renderer output. It has language,
title and tagging metadata, the Chromium and Skia producer markers,
and the two Info dates. Encryption, an existing document identifier,
and XMP metadata fall outside this shape. Resubmit fresh renderer output
if normalization needs to be retried. Operate on renderer-owned bytes
from controlled document templates.

The normalizer places its bounded input and two-date update in a private
temporary directory. qpdf reads just the trailer, Info and catalog for
the update. The rewrite retains the other Info properties and uses
qpdf's deterministic identifier with stream settings preserved. The
rewrite streams binary stdout through the existing bounded process
runner. Any nonzero qpdf exit is a failure. Cancellation or an exceeded
bound stops the process, and the private temporary directory is removed
on exit. Error messages omit document text and qpdf output.
[qpdf 12.4.2 command and JSON options](https://qpdf.readthedocs.io/en/12.4/cli.html)

The qualified local configuration uses qpdf 12.4.2 on Linux x64, with
pinned Chromium and fonts. Representative English and Portuguese
fixtures exercise selectable text, document language, headings, lists
and links. Verify the runtime and representative output again when
changing any of those dependencies. Deployment packaging, assistive
technology checks, and consumer validation remain separate evidence.

For the explicit producer test, provide a directory with `first` and
`second` subdirectories. Each holds fresh `en-US.pdf` and `pt-BR.pdf`
captures of the same synthetic documents at two different times.
Use the following test settings with the locked source build.

```sh
PANDABEAR_TEST_QPDF=/absolute/path/to/qpdf \
PANDABEAR_TEST_QPDF_FIXTURES=/absolute/path/to/synthetic-fixtures \
PANDABEAR_TEST_QPDF_ARTIFACTS=/absolute/path/to/test-output \
dotnet test --project tests/SharedKernel.DocumentRendering.Tests/SharedKernel.DocumentRendering.Tests.csproj \
  -c Release --no-build --no-restore --explicit only --filter-class '*QualifiedQpdfTests'
```
